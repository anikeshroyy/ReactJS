# React Card Showcase Mini Project

This is a simple React project that demonstrates how to build and display a collection of cards using reusable components and props.

---

## Project Goal

Create a small UI where each card is rendered from a shared component and populated with different content using props.

## What You’ll Learn

- Creating reusable React components
- Passing data with props
- Rendering multiple cards from an array
- Organizing simple project structure in React

## Features

- Reusable card component
- Dynamic content through props
- Clean and simple card-based layout
- Beginner-friendly React example

## Project Structure

- src/App.jsx - main app layout
- src/components/ - reusable UI components such as the card component
- src/App.css - styling for the project
