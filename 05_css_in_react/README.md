# 05_css_in_react

A small React + Vite project demonstrating CSS Module usage in a component-based UI.

---

## Overview

This project includes:
- `Navbar` styled with CSS Modules
- `Header` component with scoped component styles
- `Button` component demonstrating reusable styling
- `App.jsx` that composes the UI layout

## Features

- React 19 with Vite
- CSS Modules for isolated styling
- Component-driven layout structure
- Simple development and build scripts

## Project structure

- `src/App.jsx` – top-level app component
- `src/main.jsx` – React entry point
- `src/components/Navbar/Navbar.jsx` – navbar component
- `src/components/Navbar/Navbar.module.css` – navbar scoped styles
- `src/components/Header/Header.jsx` – header component
- `src/components/Header/Header.module.css` – header scoped styles
- `src/components/Button/Button.jsx` – button component
- `src/components/Button/Button.module.css` – button scoped styles
---
## Notes

This project is a learning exercise for applying CSS Modules in React components and organizing styles per component.
